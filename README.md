# Әбіш әлемі: 12 шығарма

Әбіш Кекілбайұлының 12 шығармасына арналған интерактив сайт: 3D кітап сөресі, әр шығармаға жеке инфографика, 3D көріністер, кейіпкер монологтары, мектептік акциялар, «Қай кітап саған сай?» тесті, сөздік және 7 минуттық қорғау режимі (таймер мен суфлер).

**Шығармалар:** Шыңырау · Аңыздың ақыры · Үркер · Елең-алаң · Құс қанаты · Алтын шуақ · Бір шөкім бұлт · Күй · Ханша-Дария хикаясы · Бәйгеторы · Бір шоқ жиде · Шеткері үй

**Ұран:** «Шыңыраудың тереңі — жер астында, Әбіш мұрасының тереңі — ұлт жадында».

## Ашу
`index.html` файлын браузерде ашыңыз (3D үшін интернет керек), немесе GitHub Pages арқылы жариялаңыз: Settings → Pages → Branch: `main`, папка `/ (root)`.
